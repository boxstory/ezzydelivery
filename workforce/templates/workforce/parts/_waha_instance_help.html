{# Purpose: Explain what a WhatsApp "instance" is, and why one number has two transport fields. #} {# Used by: workforce/whatsapp_instances_list.html (add + edit modals). #} {# Notes: The Evolution/WAHA split is the thing people get stuck on — both fields name the SAME number on two different senders. #}
One row = one WhatsApp number
The platform can send from that number through two senders, so it has a name on each. Fill in the one(s) you use:
  • Evolution Instance Name — its handle on the external Evolution API.
  • WAHA Session — its handle on our own WAHA bridge.
Leaving the WAHA session unset doesn't disable the number — WAHA messages go out from the default session instead, which may not be this number.
