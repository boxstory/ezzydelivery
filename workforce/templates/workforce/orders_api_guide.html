API Integration Guide

Documentation for the Orders API endpoints and webhooks

CREATE ORDER API ENDPOINT
POST /api/v1/orders/create/
Headers
Header Value Required
Content-Type application/json Yes
Authorization Token {your_api_token} Yes
Request Body
{
    "business_id": 123,
    "client_order_code": "ORD-001",
    "customer_name": "John Doe",
    "customer_phone": "+97412345678",
    "customer_whatsapp": "+97412345678",
    "customer_address": "Zone 45, Street 123, Building 5",
    "dl_zone": 45,
    "dl_street": 123,
    "dl_building": 5,
    "cod_amount": 150,
    "dl_amount": 15,
    "order_notes": "Handle with care"
}
Response (Success - 201)
{
    "success": true,
    "message": "Order created successfully",
    "data": {
        "order_id": 456,
        "order_number": "BIZCODE-ORD-001-60114-AA001",
        "status": "to_review"
    }
}
Response (Error - 400)
{
    "success": false,
    "error": "customer_name is required"
}
BULK CREATE ORDERS API
POST /api/v1/orders/bulk-create/
Request Body
{
    "business_id": 123,
    "orders": [
        {
            "client_order_code": "ORD-001",
            "customer_name": "John Doe",
            "customer_phone": "+97412345678",
            "customer_address": "Zone 45, Street 123",
            "cod_amount": 150
        },
        {
            "client_order_code": "ORD-002",
            "customer_name": "Jane Smith",
            "customer_phone": "+97487654321",
            "customer_address": "Zone 61, Street 8",
            "cod_amount": 0
        }
    ]
}
Response (Success - 201)
{
    "success": true,
    "message": "2 orders created successfully",
    "data": {
        "created": 2,
        "failed": 0,
        "orders": [
            {"order_number": "BIZCODE-ORD-001-60114-AA001"},
            {"order_number": "BIZCODE-ORD-002-60114-AA002"}
        ]
    }
}
WEBHOOK NOTIFICATIONS

Configure webhook URL in your business settings to receive order status updates.

Webhook Payload
{
    "event": "order.status_updated",
    "timestamp": "2026-01-14T10:30:00Z",
    "data": {
        "order_id": 456,
        "order_number": "BIZCODE-ORD-001-60114-AA001",
        "old_status": "to_review",
        "new_status": "published",
        "delivery_task_id": 789
    }
}
Event Types
  • order.created - New order created
  • order.status_updated - Order status changed
  • order.delivered - Order delivered
  • order.failed - Delivery failed
FIELD REFERENCE
Required Fields
  • business_id Seller's business ID
  • customer_name Customer full name
  • customer_phone Phone number
  • customer_address Delivery address
Optional Fields
  • client_order_codeYour reference (auto-generated if empty)
  • customer_whatsappWhatsApp number
  • dl_zoneZone number (integer)
  • dl_streetStreet number (integer)
  • dl_buildingBuilding number (integer)
  • cod_amountCOD in QAR (default: 0)
  • dl_amountDelivery fee in QAR
  • order_notesSpecial instructions
