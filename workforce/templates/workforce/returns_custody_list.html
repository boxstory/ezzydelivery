"Change" writes an override and says so in the timeline. The status filter defaults to "open" (with_driver/in_manifest/at_hub/ disputed — the states where somebody is still liable); "Needs triage" narrows that to rows whose destination resolved to nothing, which is the queue that actually blocks a driver. The three headline figures ARE the filters: each card links to the view it counts and lights up when that view is showing, so the number and the way into it are one target. Age comes from the view (age_label / age_band), not template arithmetic — open rows age live, closed rows report turnaround and are never banded. Receiving is one-way: CUSTODY_TRANSITIONS makes every closing state a dead end, so a second receive is refused rather than silently repeated.
