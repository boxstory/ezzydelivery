CONFIGURATION HELP

Batching Logic

When an order is verified, it enters the batching system. If a matching order (same store + zone) exists in holding, they are batched together. Otherwise, a hold window starts to wait for a match.

Hold Window

The initial wait time after the first order. If no match arrives, the batch is released as a single order delivery.

SLA Buffer

If an order's remaining SLA time falls below this buffer, it is force-released to prevent SLA breaches.

Peak Hours

During peak hours, the system may adjust hold windows for faster throughput.
