New WAHA Session
What this does
Creates an empty session on the WAHA container and starts it. It will sit on Waiting for QR scan until you open the WAHA dashboard and scan the code with the phone that should send from it. Afterwards, link it to an instance in the table so the platform actually routes sends through it.
Letters, numbers, hyphen and underscore only. This is WAHA's own handle for the number — it cannot be renamed later.
Add WhatsApp Instance
One row = one WhatsApp number
The platform can send from that number through two senders, so it has a name on each. Fill in the one(s) you use:
  • Evolution Instance Name — its handle on the external Evolution API.
  • WAHA Session — its handle on our own WAHA bridge.
Leaving the WAHA session unset doesn't disable the number — WAHA messages go out from the default session instead, which may not be this number.
