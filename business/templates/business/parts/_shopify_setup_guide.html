Shopify Setup Guide

{# ---------------------------------------------------------------- #} {# CUSTOM APP — merchant pastes a token they generate themselves #} {# ---------------------------------------------------------------- #}
Custom App

You generate the access token inside your own Shopify admin and paste it here. Client ID and Client Secret are not used on this path — leave them empty.

  1. Open the app developer area

    In your Shopify admin, go to Settings Apps and sales channels Develop apps. If this is your first app, Shopify asks you to click Allow custom app development once.

  2. Create the app

    Click Create an app, name it EzzyDelivery, and confirm.

  3. Grant the Admin API scopes

    Open Configuration Admin API integration Edit, then tick these six:

    • read_orderswe read the orders to deliver
    • write_orderswe write the tracking number back
    • read_productsproduct names and SKUs on the label
    • read_customersdelivery name, phone and address
    • read_fulfillmentsskip what you already shipped
    • write_fulfillmentsmark delivered orders as fulfilled

    Click Save.

  4. Install the app

    Go to the API credentials tab and click Install app Install.

  5. Copy the Admin API access token

    Under Admin API access token, click Reveal token once and copy it. It starts with shpat_.

    Shopify shows this token once. If you close the page without copying it, you must uninstall and reinstall the app to get a new one.
  6. Fill in this form
    Access Token
    the shpat_… value you just copied
    Store URL
    your .myshopify.com handle — see Finding your Store URL below

    Click Save. There is no authorization step on this path.

  7. Test the connection

    Press Test Connection on the saved integration. A working setup lists your recent orders and product count. Anything else — check the troubleshooting table below.

{# ---------------------------------------------------------------- #} {# OAUTH — we exchange the credentials for a token #} {# ---------------------------------------------------------------- #}
OAuth

You give us the Client ID and Secret, and we fetch the access token for you. This is two steps: save the credentials, then authorize. Saving alone does not connect the store.

  1. Open your app's configuration

    In your Shopify admin, go to Settings Apps and sales channels Develop apps your app Configuration. If your developer built the app in the Shopify Partner dashboard, the same two fields live under Apps your app Configuration URLs.

  2. Set the App URL

    Paste this into the App URL field:

    {{ shopify_oauth_app_url }}
    The App URL and the redirection URL in the next step must be on the same host. If they differ, Shopify blocks the install with "the redirect_uri and application url must have matching hosts" before you ever see the permission screen.
  3. Add the redirection URL

    Paste this into Allowed redirection URL(s), on its own line:

    {{ shopify_oauth_redirect_uri }}

    Use the Copy button rather than typing it. Shopify compares this character for character, including the trailing slash. Click Save in Shopify.

  4. Copy your Client ID and Client Secret

    Both are on the API credentials tab (Partner dashboard: Client credentials). The secret starts with shpss_. It is not an access token — it cannot call the API on its own, which is exactly why this OAuth step exists.

  5. Fill in this form
    Client ID
    from the API credentials tab
    Client Secret
    the shpss_… value
    Store URL
    your .myshopify.com handle — see Finding your Store URL below
  6. Authorize

    Click Save & Connect to Shopify. Shopify shows a permission screen — press Install / Update app. You land back here and the access token is stored automatically. Skipping this step is the single most common reason an integration sits dead: the credentials are saved, no token is ever issued, and every sync returns 401 Unauthorized.

  7. Test the connection

    Press Test Connection. A working setup lists your recent orders and product count. Our team then approves the integration and orders begin importing automatically every hour.

{# ---------------------------------------------------------------- #} {# SHARED — store URL + troubleshooting #} {# ---------------------------------------------------------------- #}
Finding your Store URL

We need the permanent .myshopify.com handle, not your customer-facing domain. Find it in Settings Domains — it is the one labelled myshopify.com, for example my-store-a1b2.myshopify.com. The Admin API does not answer on a custom domain.

If something goes wrong
What Shopify says What it means
redirect_uri and application url must have matching hosts Your App URL and redirection URL are on different domains. Both must be {{ shopify_oauth_app_url }}. There is no api. subdomain — that address does not exist.
the redirect_uri is not whitelisted The redirection URL does not match character for character. Re-copy it in step 3 and confirm you saved the change in Shopify.
401 Unauthorized No access token stored. On OAuth, the authorize step was never completed. On Custom App, the API Secret was pasted where the shpat_ token belongs.
Invalid API key or access token The token was revoked, or the app was uninstalled from the store. Reinstall the app and connect again.
404 Not Found The Store URL is wrong — usually a custom domain instead of the .myshopify.com handle.
