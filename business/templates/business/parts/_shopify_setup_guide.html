Shopify Setup Guide

To connect a Shopify store, choose one of the following:

Option 1 — Custom App (manual Access Token)

  1. In Shopify Admin go to Settings → Apps and sales channels → Develop apps → Create an app.
  2. Configure Admin API scopes: read_orders, write_orders, read_products, read_customers, read_fulfillments, write_fulfillments.
  3. Install the app, then copy the Admin API access token (starts with shpat_).
  4. Paste that token into the Access Token field on the Add / Edit Integration page on this dashboard.

Option 2 — OAuth flow (recommended)

  1. Save your Shopify Client ID, Client Secret, and Store URL on the integration form.
  2. Click Connect (OAuth) on the integration card on the API list page.
  3. Authorize the app on Shopify; the platform exchanges the code for a permanent shpat_ token automatically via /business/shopify/oauth/callback/.

Common error: pasting the API Secret into the Access Token field returns Shopify 401 Unauthorized. Use a token that starts with shpat_.
