How to fix
    {% if status == 401 %}
  1. Check the access token. On Shopify it starts with shpat_ — the API secret (shpss_) will not work here.
  2. Finish the OAuth step. Saving credentials does not connect the store; open the integration and press Connect with Shopify.
  3. Confirm the token is still valid. Uninstalling or reinstalling the app in your store revokes it.
  4. Re-enter it. Use Edit settings to paste a fresh token, then run the test again.
    5. {% elif status == 403 %}
  5. Grant the read scopes. The credentials need read_orders and read_products at minimum.
  6. Reinstall after changing scopes. Scope changes only take effect once the app is reinstalled.
  7. Check the key belongs to this store. A key from another store returns 403 against this one.
    8. {% elif status == 404 %}
  8. Check the store URL. Shopify needs the permanent .myshopify.com handle, not your customer-facing domain.
  9. Check the endpoint paths. They should look like /admin/api/2024-01/orders.json.
  10. Check the API version. Shopify retires versions; move to a current one if yours is old.
    11. {% elif status >= 500 %}
  11. Try again in a few minutes. Server errors on the store's side are usually brief.
  12. Check the platform status page. A wider outage will show up there.
  13. Contact us if it keeps failing for more than an hour.
    14. {% else %}
  14. Check the store URL. It must be reachable over HTTPS from the public internet.
  15. Check every credential. Key, secret, and access token all have to be present and current.
  16. Check the endpoint paths on the integration's settings.
  17. Contact us with the status line above if none of that helps.
    18. {% endif %}
