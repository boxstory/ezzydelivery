This is where the look of a printed receipt is decided — the paper it prints on, our details at the top, the colour and typeface, and what appears at the bottom. One template covers one kind of receipt, and whichever template is marked default for that kind is the one the system reaches for when someone prints. The same form is used to create a new template and to edit an existing one; the list at Receipt Templates is where you pick which to work on.

What you can do here

Name & type
Both required. The name is only for staff to recognise it; the type decides which printouts this template can serve.
Paper size
The physical stock it is laid out for — thermal roll widths or office paper.
Set as default
Makes this the template used automatically for its type.
Company info
Name, phone, address and email printed in the header. Useful when a receipt has to carry different contact details from the rest.
Logo
Show or hide it, and point it at a different image. Leave the URL empty to use our standard logo.
Style
Accent colour (picker and hex box stay in step), font family, and body font size between 8 and 16 pixels.
Content
Whether to print a signature line and a QR code, plus the footer message at the bottom of the slip.
Custom CSS
Free-form styling appended to the receipt for anything the options above cannot express. Leave it empty unless you know what you are writing.
Live preview
The mock receipt on the right redraws as you type, using sample settlement figures.

Template type

Settlement
The slip a driver gets when their cash is settled with the office.
COD deposit
Proof that collected cash was handed in.
Earnings
A driver's earnings statement rather than a cash receipt.
Transaction
A general one-off money movement.

Paper size

Thermal
80mm or 58mm receipt rolls — narrow, monospaced, no wide tables.
A4 / A5
Office sheets, for receipts that get filed or emailed.
Letter
US letter stock, for the same use as A4.

Worth knowing

  • Ticking Set as default silently un-defaults whatever template currently holds that spot for the same type. Only one default per type can exist, and you get no warning about the one you displaced.
  • The live preview is an approximation. It follows the company name, address, accent colour, logo toggle, signature toggle and footer only — font, paper size, QR code and custom CSS are not reflected. Use the preview action on the templates list to see the real render.
  • Nothing is saved until you press the save button. Cancel throws away every change on the form, including the ones you can see in the preview.
  • Custom CSS is applied as written, with no validation. A bad rule here shows up on every receipt printed from this template.
  • Changes take effect on receipts printed from now on. Anything already printed or saved as a PDF keeps the old look.
