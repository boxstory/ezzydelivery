Every WhatsApp message whose wording belongs to the platform lives here — the ones it sends on its own, and the starter text a staff composer opens with. Editing a body here changes it everywhere it is used, immediately, for the next send. Nothing on this page touches a server setting, so there is no reload and no deploy involved. Which number each message leaves from is decided on All Triggers, not here.

What you can do here

Message body
The text itself. Save applies it to the next send. Leaving it exactly as shipped stores nothing, so that message keeps following the built-in default even if the default is later improved.
Placeholders
The chips on the right. Click one to drop it at the cursor. Each is replaced with real data at send time — a name you type by hand would go out to every recipient unchanged.
Preview
Renders the body as a WhatsApp bubble with sample values, so bold, italics and line breaks can be checked before saving. Sample values only — it sends nothing.
Restore default text
Puts the shipped wording back in the box. It is not applied until you press Save, so you can compare first.
Sending / Off
The switch in the card header. What "off" means depends on the kind of message — see the column beside this one.
Opens on
The staff screens that open with this body. Use it to check a reworded message where staff will actually meet it.

Reading a card

Sent automatically
The platform sends this one with nobody watching. Switching it off means it genuinely stops going out.
Composer starter
Only pre-fills a textarea a staff member reads and edits before sending. Switching it off opens that composer blank — it never blocks a send.
Edited
Someone has changed this body from the shipped text. Without the badge, the card is showing the built-in default.
FROM
The number this message currently leaves from, resolved live from the sender route for its group. Change it on All Triggers.
KEY
The internal name of the message — what a log line or a support question refers to.
On/off lives on … trigger
Shown instead of a switch when an automation trigger already owns whether this message goes out. Two switches for one decision is how a page ends up lying, so this card links to the real one.

Worth knowing

  • A body is shared. The order verification text, for example, is used by the order page, the delivery task page, the verification queue's Send now and the automatic pipeline — all four change together.
  • An unknown placeholder is left in the message as-is rather than breaking the send, so a typo like {customer} will go out visibly wrong instead of silently failing.
  • Messages are grouped by sender route, which is what decides the number and the channel. Moving a number is a change on All Triggers; this page only follows it.
  • Formatting is WhatsApp's own: *bold*, _italic_, ~strike~. HTML does nothing.
  • Switching off a composer starter does not stop staff messaging that customer — it only takes away the head start.
