One identity document belonging to one driver — a QID, licence, passport or national ID. The top card shows what is on file and, when a file was uploaded, the scan itself; the card below lets you correct any of it. Use this page when a driver renews a document, when a number was typed wrong at sign-up, or when the scan is unreadable. The driver's full set of documents lives on their driver record, and the whole list of documents across the fleet is on Driver Documents.

What you can do here

Preview
The uploaded scan, shown full width. It only appears when a file has actually been attached.
Information
Read-only summary — driver name and code, document type and number, issuing country, expiry, and when the record was created and last touched.
Document type
Reclassify the record if it was filed under the wrong kind of document.
Document number
The identifier printed on the document. Required — it cannot be saved blank.
Issued from
The country or authority that issued it.
Expiry date
Drives the expired warning shown against this document on the driver's record. Leaving it empty means nothing will ever warn you.
Document file
Upload a fresh scan. Leave it empty to keep the current one.
Save Changes
Writes everything at once and reloads so the preview and the summary catch up.

Document types

QID
Qatari residence ID — the primary identity document for most drivers.
Driving License
Proof they may legally drive the vehicle class they are registered with.
Passport
Used where a QID is not yet issued, or as supporting identity.
National ID
Home-country identity card, kept for the file rather than for compliance.

Worth knowing

  • Uploading a new file replaces the old one. The previous scan is not kept, so make sure the new upload is legible before saving.
  • Files must be JPG, PNG, GIF or PDF and no larger than 10 MB. Anything else is refused with an error rather than saved.
  • A PDF will not display in the preview area — it is only meant for images. The document is still stored correctly.
  • This page edits the front side only. Documents with a back side are managed from the driver's own record.
  • The document belongs to the driver shown at the top and cannot be reassigned here. If it was attached to the wrong person, delete it from that driver's record and add it to the right one.
  • Correcting a document does not re-approve anyone. Driver approval is a separate decision on the driver record.
