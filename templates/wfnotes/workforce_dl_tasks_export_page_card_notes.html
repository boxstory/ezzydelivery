A reporting tool for delivery tasks, built around the question clients actually ask: "what did you deliver for me between these dates?" You pick one business, set a date range and optionally a status, then read the result on screen or download it as Excel or CSV. It is read-only — nothing here changes a task, a driver or an order. It works one client at a time by design, so a file can be sent straight to that client.

What you can do here

Pick a client
Step one is a tile per active business with its all-time task count. Choosing one moves you to the filter view; the breadcrumb takes you back.
Date From / To
Filters on the task's own delivery date. Left alone it shows yesterday and today.
Task Status
Narrows to a single state, or leave it on all statuses.
Filter
Reloads the table with your choices. The filters live in the address bar, so the view can be bookmarked or shared.
Export Excel
Downloads the filtered set as a spreadsheet, named with the date range.
Export CSV
The same rows as plain comma-separated text, for importing elsewhere.
Open a task
The task number and the order code are both links and open in a new tab, so you keep the filtered list behind you.
Count badge
Next to the export buttons — how many tasks the current filter matched.

Task statuses

New
Raised but not yet moving — no driver has taken it on.
Pending pickup
Accepted, waiting for the goods to be collected.
Out for delivery
On the road with a driver.
Delivered
Completed. The completed-at column and any COD collection apply here.
Failed
Attempted but not delivered. The failure reason column explains why.
Cancelled
Called off before delivery, usually with the order.
Returned
Goods came back to us instead of reaching the customer.

Worth knowing

  • Step one lists active businesses only. If a client is missing, check their account status on their business record rather than assuming they have no tasks.
  • The number on a client's tile is their lifetime task count. It has nothing to do with the dates you are about to choose.
  • Dates match the task date, not the day the task was completed. A task delivered late still reports under the date it was scheduled for.
  • The table is not paginated, so a wide date range on a busy client renders every matching row at once — narrow the dates before loading a whole year.
  • The download contains the same rows as the screen plus a resolved Zone Name column, and it follows the filters currently in the address bar.
  • COD amounts here come from the order and the collected flag from the task. This is a delivery report, not a settlement record — use the COD Ledger for money questions.
