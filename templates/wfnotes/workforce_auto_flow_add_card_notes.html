This is the builder for a single automation flow — one rule that says "when this happens, do that". You pick a trigger from the catalogue maintained on Auto Triggers, optionally narrow it with conditions, then choose one action and fill in its settings. Saving takes you back to Automation Flows, where the flow can be switched on, test-run, and inspected in its log. The same page is reused when you edit an existing flow.

What you can do here

Flow name
Free text, shown on the flows list and in every log entry. Describe the outcome, not the mechanics.
Trigger
The event that starts the flow, grouped into WhatsApp, Webhook and System. Picking one shows its description, the underlying action it maps to, and its category — and opens the condition panel for that category.
Apply to
Limit the flow to one client, or leave it on all businesses.
Conditions
Extra gates that must all pass before the action runs — a specific status, a COD rule, a webhook event, a from → to status move, verified addresses only, or driver-assigned only. Which set you see depends on the trigger's category.
Active hours
Only fire between these two times. Leave both empty for 24/7.
Max per day
Cap on how often this flow may fire in a day. Blank means unlimited.
Action
What the flow does. Choosing one swaps the right-hand Action Config panel to that action's settings.
Flow summary
Appears once both a trigger and an action are chosen — a one-line read-back of the rule before you save.

Actions you can pick

WhatsApp
Send a message. You choose the sending number, the recipient (customer, driver, seller, staff, a custom number or a group), a message template with {variable} placeholders, and an optional delay in seconds.
Webhook
Call an external URL with GET, POST or PUT. Custom headers and the payload body are both JSON; an empty payload sends the full event data.
Order status
Move the triggering order to a chosen status, or every order of the same business.
Task status
Move the delivery task to a chosen status, with an optional note recorded against the change.
Assign driver
Nearest, least loaded, zone-based, or one named driver — with an option to notify them afterwards.
Notification
In-app message to the assigned driver, all staff, or the business owner, with a title, body and severity.
Create task
Raise a delivery task — standard, hub delivery or return — at a chosen starting status, optionally published to the fleet straight away.

Worth knowing

  • A new flow is live the moment you save it. If it isn't ready, switch it off on the flows list.
  • A flow only fires when both it and its trigger are enabled. Enabling the trigger is done on Auto Triggers, not here.
  • Only the config panel matching the selected action is used. Anything you typed into a different action's panel before switching is ignored on save.
  • Re-opening a saved flow does not refill every condition dropdown — the status and event pickers come back blank, so re-select them before saving or they will be cleared.
  • Conditions and action settings are stored together as the flow's config; you can read the stored values back with View in the Config column on the flows list.
