Every row here is a raw order line we pulled from a client's own system — their Shopify or WooCommerce shop, a OneDrive or Google spreadsheet, or a public order link. It is not a real order yet. This page is the full history for one client at a time: pick a business and you get all of their rows, oldest to newest, so you can hunt down a specific line, see why it never became an order, and push it through. Nothing appears until a business is selected.

What you can do here

Business
Required. Choosing one reloads the page straight away; the counts beside the Status and Source options are that client's totals.
Filters
Narrow by status, by source, and by sort order. Search matches order code, customer name, phone, address and the platform's own order id.
Row click
Clicking anywhere on a row except a control opens the detail popup with the full record, including the raw data exactly as the source sent it.
Resync
Re-fetches the selected rows from their original source and re-applies the current column mapping. Rows that actually changed flash yellow.
Resync filtered
The same thing for every row matching the filter, not just the ticked ones. Capped at 500 rows and can take a while.
Mark Imported
Flags the ticked rows as done without creating anything — purely to clear them out of the New queue when they were handled elsewhere.
Auto-Import
Runs the full pipeline on the ticked rows: refresh from source, read the address, match products, raise the pickup, place the pin, set status, message the customer, publish to drivers. A report shows what each row did.

Row status

New
Collected, not yet turned into anything. This is the working queue.
Imported
Dealt with. When a real order was created its number is shown next to the badge; when the row was only marked imported, there is no number.
Skipped
Deliberately passed over — the row is kept for the record but is not waiting on anyone.

Auto-import outcomes

Fully automated
Every enabled stage passed; the order exists and went out to drivers.
Needs review
The order was created but something needs a human — usually the address or the pin. Read the warnings on the row.
Failed
No order was created. The row stays as it was, so it can be fixed and retried.

Worth knowing

  • Mark Imported creates nothing. Used by mistake it silently buries real orders that were never delivered — the customer never hears from anyone.
  • Auto-import takes at most 25 rows per run, and it creates real orders that can go straight to drivers. Which stages actually run is set per client on Auto-Import Stages.
  • Resync overwrites the row with what the source says now. If the client edited their sheet after we collected it, the older values are lost.
  • Resync depends on that client having a column mapping; rows with no mapping come back reported as skipped rather than updated.
  • The auto-import report deliberately stays open when anything needs reviewing. Read it before closing — closing is what refreshes the list.
