An area is the name a customer actually writes in their address — Fereej Al Asmakh, Al Najada, Muaither — and every one of them belongs to a zone. This page is the full list of those names, in English and Arabic, with the point on the map each one refers to. It matters because area names are how a written address gets turned into a zone number, and because the pin is what a driver is sent to when nothing more precise is known.

What you can do here

Search
Matches the area name in English or Arabic, and also the parent zone's name or number — so searching a zone number lists everything inside it.
Zone filter
Jump straight to one zone. Only zones that actually have areas appear in the list, with their area count in brackets.
Did you mean
When a search finds nothing, the page suggests the closest real names it knows, each showing the zone it sits in. Clicking one runs that search.
Edit Pin
Opens a map for that area. Drag the marker to the right spot — the coordinates update as you drag — then Save Pin. The row updates without a page reload.
Show on map
The small pin next to the coordinates opens that exact point on a map inside the row — the quickest way to sanity-check a location before moving it.

What the columns mean

Zone
The zone number this area belongs to, with the zone's name beside it. Each area belongs to exactly one zone.
Arabic name
The Arabic spelling, if we hold one. A dash means it is missing, so Arabic-language searches for that area will not find it.
Coordinates
The area's point. A dash means no pin has ever been set for it.
Status
Active areas are in normal use; Inactive ones are kept for the record. Only active areas are offered as spelling suggestions.

Worth knowing

  • Saving a pin writes over the old coordinates immediately, with no confirmation and no undo. Check the point on the map first if you are not certain.
  • Moving a pin does not change any existing order or delivery — those keep the coordinates they were created with. It only affects what happens from now on.
  • An area's pin is not the same thing as its zone's boundary. Zone assignment is decided by boundaries on the zone list and polygon editor; this page is about the point inside.
  • Areas are added and removed in the admin — this page edits the pin only.
  • The two counters at the top cover every area in the system, not just what your filters show.
