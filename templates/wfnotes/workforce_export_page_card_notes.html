Pulls an order sheet out of the system for one client, as Excel or CSV. It runs in three steps — pick the client, pick where the orders come from, then set a date range, preview what you are about to download and export it. The breadcrumb under the header is how you step back. Nothing here changes an order; it is a read-and-download page.

What you can do here

Pick client
Every active client, with how many of their orders we hold and badges for any store connection they have set up.
Pick source
Our own database, or the client's store. A store card only appears if that connection has been set up and verified for them.
Date from / to
The window to pull. It starts on yesterday-to-today rather than everything, so widen it deliberately.
Order status
Database source only — hold for review, ready to pickup, published, delivered or cancelled.
Filter
Builds the preview. Until you press it nothing is fetched, so a blank screen at this step is normal.
Export Excel / CSV
Downloads exactly what the filter matched — the whole set, not just the page you can see.
Row ticks
On the live Shopify preview only. Tick rows and the export narrows to those; the badge switches to a "selected" count and Clear resets it.
Order link
In the database preview the order code opens that order in a new tab.

The sources

Database
Orders already imported into EzzyDelivery. The richest sheet — building, street, zone, coordinates, map links, scheduled slot and up to five products per order.
Shopify (live)
Goes to the client's store and reads orders straight out of it, so it includes orders we have never imported. Narrower sheet — up to three products, and the COD column is left blank on orders the store already marked paid.
WooCommerce
Despite the label, this returns the WooCommerce orders already in our database rather than a live read of the shop.

Worth knowing

  • The Database source only lists orders on the Shopify platform or with no platform set — manual and Shopify imports. Orders imported from WooCommerce come out under the WooCommerce card instead, which is why a client's totals can look short.
  • A live Shopify pull depends on the client's stored credentials. If they are wrong or expired you get a red error band rather than an empty list — that is a connection problem, not a "no orders" answer.
  • Exports are capped at 10,000 rows. Split a big pull by date rather than hoping it all comes through.
  • The date range works on the order date, and the export always re-runs the filter — so an export can include rows added since you pressed Filter.
  • Live Shopify results are held in the page, not saved. Reloading or stepping back means fetching them again.
