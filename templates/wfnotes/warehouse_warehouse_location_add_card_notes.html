Adds a pickup or dispatch point to a warehouse — a place a driver is sent to collect from or deliver to. It is an address on the map, not a shelf: nothing is ever stored here. Superadmin only.

The fields

Warehouse
Required — the building this door belongs to.
Name and code
Both required. The name is what staff read; the code is the short reference on records.
Address
Written for a driver who has never been there — the gate, the building, the landmark.
Zone number
The delivery zone the address sits in. It feeds routing, so an approximate guess causes real mis-routing.
Latitude / longitude
Optional but worth having — the pin is what a driver navigates to. Leave blank rather than guessing.
Operating hours
Free text. Say when someone is actually there to hand goods over.

Flags

Active
Only active points are offered for new pickups.
Default
The one assumed for this warehouse when nobody picks. One per building is the sane arrangement.

Good to know

  • Not a storage location. Bins and shelves are created from the warehouse capacity setup, not here.
  • Saving returns you to the list, grouped by warehouse with defaults first.
