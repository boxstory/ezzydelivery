Some clients push their orders to us automatically instead of typing them in or letting us pull them from a store. This page is how that door is opened and watched. Each active client can be given a private webhook address; anything posted to that address arrives as an order in the normal queues. The upper table is one row per active client and the key they hold; the lower table is a live record of the last hundred calls that actually came in, including the exact data sent. When a client says "we sent it and it never showed up", this is where you find out what really happened.

What you can do here

Generate
Creates the client's webhook address for the first time. The new URL is shown and copied to your clipboard so you can hand it over.
Regenerate
Issues a brand new address for a client who already has one. Use it when a key has leaked or a client asks for a reset.
Copy URL
Puts the full address on your clipboard without changing anything. This is the safe way to re-send an address someone has mislaid.
Received
A running count of every call that key has ever taken, with the last time it was used beside it. A key with no last-used date has never been tried.
View payload
Opens the exact data the client sent, plus the headers and any error message. This settles most arguments about missing fields on its own.

Log status

Received
The call arrived and was recorded, but no order came out of it yet. Open the payload — usually the data was not in a shape we recognise.
Processed
The call was accepted and turned into orders. The Orders column says how many.
Error
Something failed while handling it. The reason is shown in red under the payload.

Key status

Active
A key exists and the address will accept posts.
None
No key was ever made for this client. Nothing they send can be accepted until you generate one.

Worth knowing

  • Regenerating breaks the old address immediately. Anything the client is still posting to it stops arriving until they update their end — warn them first.
  • The address is a password in a URL. Anyone holding it can create orders on that client's account, so send it privately and never paste it into a shared thread.
  • Only clients whose account is active are listed. If a client is missing, activate the account first.
  • The log holds the most recent hundred calls only, across all clients. On a busy day evidence of a morning problem can be gone by the afternoon — grab the payload while it is there.
  • A row logged here means the call reached us. Delivery of the resulting orders, and anything that happens to them afterwards, is tracked on the Orders pages.
