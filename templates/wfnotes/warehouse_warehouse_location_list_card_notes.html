The doors of a warehouse — the pickup and dispatch points a driver is sent to, with their own address, zone and opening hours. These are outward-facing places on the map, not storage inside the building. Nothing is ever stored in one.

Reading a row

Warehouse
The building this door belongs to. One warehouse can have several — a main gate, a returns counter, a separate loading bay.
Code
The short reference staff use when saying which door a collection is from.
Default
The one assumed when nobody picks. Defaults sort to the top of each warehouse's group.
Zone
The delivery zone the address falls in — it is what drives routing, so a wrong zone sends drivers the wrong way.
Active
Inactive points stop being offered for new pickups but stay on historical records.

Good to know

  • Not storage locations. Zones, racks, shelves and bins live on the Storage Locations page; these are addresses a driver drives to.
  • Coordinates matter here more than anywhere else — this is where a driver is actually sent.
  • Filter by warehouse to see one building's doors when the list gets long.
  • Superadmin only for adding and editing.
