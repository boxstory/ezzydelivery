Confirms removing a storage location. This cannot be undone, and it takes everything nested underneath with it — deleting a zone deletes its racks, shelves and bins. Check what is stored there before you confirm.

Before you confirm

Is it empty?
Stock rows point at this location. Move the units to another bin first — deleting is not a way to zero stock.
Children go too
Deletion cascades down the tree, so a zone takes its whole branch with it.
Is deactivating enough?
If the shelf still exists but is out of use, editing it to inactive keeps the history and the codes intact.

Good to know

  • The deletion is logged with the location code and who did it.
  • Re-creating the same code later does not restore the old location or anything that pointed at it.
  • Rebuilding a whole layout? Use the capacity generator, which can clear and regenerate in one controlled step.
