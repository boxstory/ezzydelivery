The last gate before a delivery becomes real work. Every row is a delivery task that has been created but never pushed to the fleet — so no driver can see it, claim it or be assigned it. The list builds itself: a task appears the moment it is raised and disappears the moment it is published or closed. An empty page is the correct state. Publishing an order to delivery is step one; this page is step two.

What you can do here

Publish one
The paper-plane icon next to the Not Published badge pushes that single task out to the fleet drivers.
Publish many
Tick rows to open the action bar, then Publish Fleets or App. The same bar can assign a driver, print, set a status on the whole selection, or export it.
Update status
The dot button beside the status badge opens the status modal for that task without leaving the queue.
Open a task
Click the row or the eye icon for the full delivery-task page — useful when the address or COD looks wrong before you publish it.
WhatsApp
Messages the customer with their location-verification link, for when the address needs confirming first.
Publish to Task
The header button jumps back one step, to the orders that have no delivery task at all yet. Its badge is a live count of those orders.

What is in the queue

Included
Tasks belonging to an active client that are still open and have never been published.
Excluded
Anything already finished or dead — delivered, partially delivered, cancelled, failed or rejected — even if it was never published.
Order
Newest task first, so anything sitting near the bottom has been waiting the longest.

Worth knowing

  • A task can show a real status such as Pending or Assigned and still be sitting here. Status is not visibility — publishing is.
  • Publishing cannot be undone from this list. Once a task is out, it disappears from this queue and is managed from the task pages instead.
  • Tasks for a deactivated client never appear here, so a "missing" order may simply belong to a client whose account is not active.
  • There are two separate backlogs. Publish to Task is orders with no task yet; this page is tasks with no fleet. Clearing one does not clear the other.
