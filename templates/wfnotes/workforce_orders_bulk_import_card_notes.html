For the client who sends a spreadsheet. Upload their CSV or Excel file, tell us which of their columns is which, check the rows, and the page creates the orders one at a time while you watch. The whole run is attached to the seller you pick at the start, and what happened is kept on Import History. Orders that come in through a shop or a sheet connection go through the Import Wizard instead.

What you can do here

Select seller
Required. Every order in the file is created under this client, so a wrong pick means a whole batch under the wrong name.
Upload
Drop a file on the box or click to browse. CSV, XLSX and XLS are accepted. The cross clears it if you grabbed the wrong one.
Sample files
Download a ready-made CSV or Excel with the right headings to send to a client who does not know what to give us.
Map columns
Match each column in their file to one of our order fields. Common headings are detected for you; the counters at the top show how many columns were found and how many you have wired.
Save mapping
Keeps the wiring for this client so the next file from them comes in pre-mapped. Reset to Auto-detect throws it away.
Preview & edit
The rows as they will be saved. Click any cell to correct it before importing — a missing zone, a phone with a stray space.
Start import
Runs the batch with a live progress bar and a running log of every row as it succeeds or fails.
Retry failed
Rows that failed come back in an editable table with the reason attached. Fix them and retry just those — the successful ones are not touched again.
Import more
Clears the wizard back to step one for the next file.

The columns

Required
Customer name, phone and address. Everything else is optional and can be filled in later.
Order ID
The client's own reference for the order. Map it whenever they have one — it is how they will ask you about it later.
Zone / street / building
The Qatar national address numbers. Mapping them saves someone parsing the address by hand afterwards.
COD amount
Cash the driver must collect at the door.
Delivery fee
What we bill the client for the job. Not collected from the customer — do not map a total into this.
Product columns
Repeating product-and-count pairs, for files that list several items across one row.

Worth knowing

  • Orders are created one row at a time. If you close the tab halfway, everything up to that point is already in the system — go and check before re-running the file.
  • A failed row does not stop the batch. The rest keeps going and the failures are handed back for you to fix, so read the log rather than assuming the run was clean.
  • The file is read in your browser. A very large spreadsheet will be slow on a weak machine, and nothing is uploaded to us until you press start.
  • Edits in the preview change what we save, not the client's file. Their copy still holds the bad value.
  • Duplicates are caught by the client's order code, and a row whose code we already hold is rejected. Rows with no order code get one generated, so re-running a file without codes will happily create the same orders again.
  • Imported orders arrive needing review and address verification like any other.
