The on/off switchboard for temp-order sync — the process that pulls a client's orders out of their shop, sheet or link and parks them as raw rows for staff to check before they become real orders. One row per client, with a switch on the right. The rest of the row is context for that decision: what we already hold for them, which import sources they have, and which source is treated as their default when a row is mapped.

What you can do here

Temp Sync
The switch that turns syncing on or off for that client. It saves the moment you flip it — no Save button — and the counter above the table follows along. If the save fails the switch flips itself back.
Edit mapping
The pencil in the Default Mapping column opens the mapping manager for that client, where you say which spreadsheet column or platform field feeds which order field.
Go to Orders
Jumps to the real orders list — what these rows eventually become.
Back to Temp Orders
Returns to the queue of raw rows waiting to be reviewed and imported.

Reading the columns

Temp Orders
How many raw rows we already hold for that client, in any state.
OneDrive
Active OneDrive spreadsheet sources configured for them.
API
Store connections on file — Shopify, WooCommerce, TikTok Shop, Google Sheet. Counts all of them, approved or not.
Public Link
Active public order-form links the client hands out.
Default Mapping
Which source is the client's primary one, preferring an explicitly defaulted OneDrive sheet, then a default approved store connection, then a public link. A dash means nothing has been marked default.

Worth knowing

  • Switching sync on with no source and no mapping achieves nothing — rows either never arrive or arrive unreadable. Check the source columns and the Default Mapping badge first.
  • Turning sync off stops new rows only. Rows already collected stay in Temp Orders and can still be imported.
  • Only clients switched on here appear on the Auto-Import Stages page, so switching a client off also removes their stage configuration from view.
  • Every business is listed regardless of account status, sorted active first. Check the Status badge before enabling — a suspended client should not normally be syncing.
  • The API count is a count of connections, not of working ones. A client can show a connection here that is still pending approval on the seller API configs page.
