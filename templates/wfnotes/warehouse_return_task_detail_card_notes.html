Putting one cancelled order's items back where they came from. Each line shows the product and the shelf it was picked from; confirm a line once it is physically back, and the stock figure for that location goes up again. Opening this page claims the task and starts it.

Working the task

Confirm a line
Adds the units back to that location and writes a return movement, so the correction is visible in the ledger.
Sorted by shelf
Lines are ordered by location so the page reads as a walk rather than a jumble.
Progress
Lines returned out of lines total. The task completes once the last one is confirmed.
Already confirmed
A confirmed line is skipped if pressed again, so stock cannot be added twice by a double tap.

Good to know

  • Confirm at the shelf. The system now says the units are there — if they are still on a trolley, the next picker will not find them.
  • Put it back where it came from where you can. The line restores stock at its original location.
  • Damaged on the way back? Return it, then correct the quantity with a cycle count so the write-off is recorded properly.
