When a raw imported row is auto-imported from Temp Orders, it runs through a fixed pipeline of steps: read the address, match products, arrange the pickup, place the pin, set the status, message the customer, hand it to the fleet. This grid decides, per client, which of those steps are allowed to run. A ticked box means the step runs for that client's rows; an unticked box means it is skipped and, where it matters, left for a human. Only clients with temp-order sync switched on appear here.

What you can do here

Tick a box
Turns that one stage on or off for that one client and saves at once — there is no Save button. A toast confirms it; if the save fails the tick springs back.
All on / All off
In a column header — applies that stage to every client with temp-order sync on, after a confirmation. The reply tells you how many changed.
All / None
In the Row Actions column — turns every stage on or off for that one client in a single save.
Back to Temp Orders
Returns to the temp order queue, where auto-import is actually run.

The stages

AI parse
Reads the free-text address and pulls out zone, street and building. Off means whatever the source supplied is used as-is.
Match products
Tries to line the imported item text up against the client's product catalogue.
Auto pickup
Raises the first-mile collection job for the order, following that client's rule on Pickup Automation.
Geocode
Turns the parsed address into a map pin via QNAS so the driver has somewhere to navigate to.
Set publish
Moves the new order's status to publish instead of leaving it for review.
Send WhatsApp
Messages the customer a link to confirm their own address. Leave it off for clients who do not want us contacting their customers.
Publish to fleet
The last step — makes the delivery job visible to drivers. Off means the order is created but nobody is offered it until staff publish it.

Worth knowing

  • Stages default to on. A client who has never been configured here behaves as if every box were ticked.
  • The column bulk buttons hit every listed client at once, including rows you have scrolled past. There is no undo — you would have to set them back one by one.
  • Changes apply to future auto-imports only. Rows already imported keep whatever happened at the time.
  • An empty table means no client has temp-order sync switched on yet — turn it on from Temp Order Config and they will appear here.
  • Turning a stage off does not block the import; it just leaves that piece of work undone, so expect those orders to land in the review queue instead of going straight out.
