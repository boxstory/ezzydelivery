Creates one storage location by hand — a zone, rack, shelf or bin. Use it for a single addition or correction; a whole warehouse layout is far quicker to build with the capacity generator, which creates every level at once and names them consistently.

The fields

Warehouse
Which building it belongs to. A seller account may only pick warehouses its business is linked to.
Type
Zone, rack, shelf or bin. Only bins hold stock — the rest exist to address them.
Parent
What it sits inside. A location with no parent floats outside the tree, which makes it hard to find and easy to forget.
Code
The reference staff read on the shelf. Follow the pattern the rest of the warehouse already uses.
Name
The human label, shown beside the code in the tree.

Good to know

  • Match the building. A code that does not exist physically sends pickers to a shelf that is not there.
  • Keep codes consistent with the generated ones, or sorted lists and pick routes stop reading in order.
  • Parent must be in the same warehouse — you cannot hang a bin off another building's shelf.
  • Saving returns you to the tree, where the new location appears under its parent.
