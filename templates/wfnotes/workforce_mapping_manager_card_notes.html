Incoming orders arrive with whatever column names the client's own system uses. This page is where you tell EzzyDelivery which of their columns means which of our fields, for one business at a time. Each connection type gets its own tab and its own mapping, so a client sending orders from both Shopify and a spreadsheet can have two different sets of rules. The mapping is what the importer reads every time an order comes in, so a wrong line here shows up as a customer name in the phone field, not as an error.

What you can do here

Business
Pick whose mapping you are editing. The page reloads on change. Only active businesses are listed.
Platform tabs
One tab per connection type. Switching tabs does not lose your edits — every tab is held until you save.
Source badge
Shows which connected source the tab is reading. Where a client has several, Set Default chooses the one used from now on.
Fetch Headers
Pulls the live column names out of the connected source and fills the dropdowns with them. Do this first — mapping against stale headers is the usual cause of blank fields.
Upload Sample
Reads headers from an Excel or CSV file you supply, for when the source cannot be reached but you have a specimen file.
Sheet picker
On Google Sheet, chooses which worksheet tab inside the workbook the headers come from.
Auto-fill
Guesses the mapping by matching header names, and applies the built-in defaults on Shopify and WooCommerce. Always review what it did.
Clear
Empties the mapping on the tab you are looking at. Nothing is written until you save.
Formula button
Switches a row from one column to a pattern, so several columns can be joined into one field using {column} placeholders — first and last name into one customer name, for instance.
Run Test
Fetches the client's most recent real order and shows what each field would resolve to under the current mapping. The fastest way to catch a mistake before it reaches an order.
Raw Data
Shows the untouched payload the source sent back, so you can see the real column names and copy the JSON.
Save All
Writes the mappings for every platform at once, not just the open tab. Discard reloads the page and throws the lot away.

The tabs

Shopify
Fixed column list from the Shopify order payload, with a default mapping already worked out — usually only needs Auto-fill.
WooCommerce
Same idea, against the WooCommerce order payload.
CSV / Excel
Column names are typed by hand, because the file is not known in advance. Also where a legacy mapping made before tabs existed appears.
Google Sheet
Headers come from a connected sheet; the mapping is stored against that sheet, not just the business.
OneDrive
Headers come from the workbook of a connected OneDrive source, and are remembered between visits so the page does not re-download it.
Public Link
A shared spreadsheet link. The tab only appears once the client has at least one active public link source.

Worth knowing

  • Four fields are required — customer name, phone, address and COD amount. They carry a req badge and are marked red until mapped; the counter at the top tells you how many are still missing.
  • A tab with no columns in its dropdowns has not had its headers loaded yet. Fetch them or upload a sample rather than assuming the source is empty.
  • Mapping changes apply to orders imported from now on. Orders already brought in keep whatever they were given.
  • For OneDrive, Google Sheet and Public Link the mapping is saved against the selected source, so a client with two sheets can map each of them differently — check the source badge before you edit.
  • Nothing is written until Save All. Leaving the page, switching business or hitting Discard loses every unsaved change on every tab.
