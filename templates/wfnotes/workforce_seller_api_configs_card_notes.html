Every card here is one connection between a client's store and us — the credentials we use to pull their orders in automatically instead of typing them. A client saves the connection from their own dashboard; it arrives here as Pending and stays inert until a staff member tests it and approves it. Once approved, the connection starts feeding rows into Temp Orders, which is where those rows are reviewed and turned into real orders.

What you can do here

Filters
Narrow the list to Pending or Approved, and/or to one client. The two stack, so you can look at just one client's pending connections.
Google Sheet
Pick a client, paste a Sheet link, add an optional label, press Link. That creates (or overwrites) their Google Sheet connection and marks it approved straight away — no separate approval step.
Test Connection
Opens a test console for that connection and tries a live fetch of orders and products, so you can see whether the credentials really work before approving.
Approve / Revoke
Flips the connection between approved and pending on the spot. The badge and the button both update without a page reload.
Seller Profile
Jumps to that client's full profile page for context — contact details, status, history.

Connection types

Shopify
Pulls orders from a Shopify store using an access token. The store URL must be the .myshopify.com handle, not the shop's own domain.
WooCommerce
Key-and-secret access to a WordPress shop's REST API.
TikTok Shop
Shop id, cipher and refresh token for a TikTok Shop seller account.
Google Sheet
A shared spreadsheet the client keeps their orders in. The label you type is what identifies the sheet later in the import screens.

Card fields

Approved
The connection is trusted and may be used to import. Pending means it is saved but not yet cleared for use.
Default
Marks which connection is the client's primary one when they have more than one. Only one per client should say Yes.

Worth knowing

  • Approving is a trust decision, not a test — nothing verifies the credentials for you. Run Test Connection first, or you approve a connection that silently imports nothing.
  • The API key on the card is truncated for display. Never treat what you see as the full key when comparing against what a client sent you.
  • Linking a Google Sheet for a client who already has one overwrites the existing sheet link rather than adding a second.
  • Google Sheet testing needs the server's Google authorisation to be in place; if sheet tests fail for every client at once, that is the cause, not the individual sheet.
  • Revoking stops future imports. Rows already pulled into Temp Orders and orders already created stay exactly where they are.
