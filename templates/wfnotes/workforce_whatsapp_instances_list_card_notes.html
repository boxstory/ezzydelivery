Every WhatsApp message the platform sends — order updates, address-verification requests, driver alerts, marketing blasts — leaves from one of the numbers listed here. Each row is one connected WhatsApp line, matched against what the messaging server actually reports right now. This page is where numbers are registered and named; deciding which part of the platform sends from which number is done on the Auto Triggers page. Come here when messages have stopped going out, when a number has been re-linked, or when a new line needs adding.

What you can do here

Add Instance
Registers a line by hand. The instance name must match the name on the messaging server exactly, or the row will never connect.
Label
Your own name for the line — Main, Support, Fleet. This is what staff pick from when routing a section to a number, so make it obvious.
Default
The line used whenever nothing more specific has been chosen. Only one row can hold it; ticking it on a second row silently takes it off the first.
Active
Untick to retire a line without deleting it. Inactive lines cannot be picked when routing a section.
Edit
Changes the label, names, number and flags. It does not touch the messaging server — nothing here connects or scans a QR code.
Delete
Removes our record of the line. The line itself keeps existing on the messaging server.

Status column

Connected
The line is linked and able to send right now.
Disconnected
The server knows the line but it is not linked — usually the phone has been logged out and the QR needs scanning again. The raw state is shown in the badge.
Not Active
We have a record of it but the messaging server has no such line at all. Either the name is spelt differently there, or it was removed.
Unknown
We could not reach the messaging server, so no live state could be read. The warning at the top of the page explains why.
Disabled
Marked inactive by staff. Separate from the live state — a line can be connected and still be disabled here.

Worth knowing

  • The list syncs itself on every page load. Any line found on the messaging server that we do not already have is added automatically, named after its number.
  • Because of that sync, deleting a row that still exists on the server brings it straight back on the next refresh, with a plain auto-generated label. To retire a line properly, untick Active instead.
  • Editing a row here changes our record only. Connecting, restarting or re-scanning a line is done on the messaging server's own dashboard.
  • The WAHA session field is for the same number reached through the other bridge. Leave it blank unless someone has told you the session name — a wrong value is worse than an empty one.
  • This page is superuser-only, and a wrong change here silently stops messages across the whole platform. Check the Auto Triggers routes after any change.
