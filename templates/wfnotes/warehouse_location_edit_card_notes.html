Changes one storage location — its code, name, type or place in the tree. Stock rows, put-away tasks and pick routes all point at this location, so an edit here changes what those pages display. Nothing about the stock itself moves.

What an edit affects

Code
Shown on stock rows, pick routes and count sheets. If the shelf label says something else, picking slows to a crawl.
Parent
Moves the location within the tree. Everything under it moves with it.
Type
Rarely right to change on a live location — a bin holding stock that becomes a shelf leaves stock in a container level.
Quantities
Untouched. Whatever was in this location stays in it, under the new label.

Good to know

  • Relabel the shelf too. The system and the building have to agree, or the code is worse than useless.
  • Existing bin codes are not rebuilt when a parent is renamed — check the children still read correctly.
  • Emptying a location is a stock job, not an edit: move the units with a put-away or correct them with a count.
