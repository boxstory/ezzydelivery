Clients who keep their orders in an Excel file on OneDrive get a source row here. A source ties one shared workbook to one business. Unlike the other import channels, OneDrive is worked hands-on from this page: you open the workbook, pick a sheet, page through the actual rows, tick the ones you want, map the columns, and import. Rows already imported are remembered so the same line is not brought in twice.

What you can do here

Add source
Business, a label to recognise it by, and the share link. Share the file as anyone with the link first, or we cannot open it.
Browse
Downloads the workbook and lists its sheets with row counts. The sheet used last time is starred and opens automatically, positioned near where the last import stopped. Disabled while the source is inactive.
Go to row
Jumps the preview to a specific spreadsheet row number. Row 1 is always treated as the header.
Row ticks
Choose exactly which rows to bring in. Rows already imported are highlighted, show their order number, and start unticked.
Map columns
Point each spreadsheet column at one of our order fields. A saved mapping loads automatically; otherwise headers are matched by name as a starting guess.
Save mapping
Stores the mapping against the source so the next import starts correct. Reset throws it away and guesses from the headers again.
Import
Creates real orders from the ticked rows using the mapping on screen, after a verification step.
Edit / power / delete
Change the label or link, park a source without deleting it, or remove it entirely.
Import history
The header link opens the log filtered to OneDrive runs, with the raw rows and errors of each one.

Reading a row

Status
Active can be browsed and imported; Inactive is parked and its Browse button is disabled.
Last import
When the source was last imported, how many orders it produced and who ran it. Never means it has not been used yet.

Required columns

Must map
Customer name, phone and address. The import refuses to run until all three are pointed at a column.
Worth mapping
Order ID, zone, street, building, COD amount, product and quantity, notes and a location link — anything left unmapped simply arrives empty on the order.

Worth knowing

  • Browse reads the workbook live every time. A client editing the file while you work means the preview and the import can disagree — re-browse before importing anything sensitive.
  • The already-imported marks are matched by spreadsheet row number. If the client inserts or deletes rows above, those marks shift and previously imported lines can look new.
  • Import creates real orders straight away — there is no staging step and no undo from this page.
  • Deleting a source removes the connection, not the orders already imported from it.
  • A saved mapping belongs to the source, not the sheet. Switching to a differently laid out sheet in the same workbook means checking the mapping again.
