Raises a return request against one delivered order. Tick the items the customer is sending back, set the quantity for each, and give a reason. This only records the expectation — nothing is received and no stock moves until the parcel physically arrives and is inspected.

Filling it in

Items
Only order lines linked to a product record can be returned, because the return has to land against real stock.
Quantity
Defaults to the whole line and is capped at what was ordered — you cannot take back more than went out.
Reason
Applies to the return and is copied onto each line. Pick the closest match; the notes box is for the detail.
Warehouse
Chosen for you — the seller's active warehouse link. If the seller has none, the return is created without one and cannot restock until that is fixed.

What happens next

You land on the RMA
With its own number, sitting at requested.
Receive, then inspect
Mark the parcel received when it arrives, then judge each item's condition. Restocking happens there, not here.

Good to know

  • No stock changes on this page. Creating a request never adds units back.
  • One request per batch of goods — if the customer sends more back later, raise a second return.
