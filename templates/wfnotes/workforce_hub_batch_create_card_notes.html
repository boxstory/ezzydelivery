This builds one hub pickup batch — a single driver ride that collects several of a client's orders from one pickup point and drops them at a hub warehouse. Set the route and the pay on the left, tick the orders that go on the ride on the right, then create. You land straight on the new batch's page, and the batch also appears in Hub Pickup Batches.

What you can do here

Pickup location
Where the driver collects — a client's active pickup point. Required.
Hub warehouse
Which active warehouse location the goods are dropped at. Required, and it becomes the origin of every last-mile task later.
Assign driver
Optional. Leave it unassigned and the batch is created Pending; pick an approved driver and it is created Assigned. You can assign or change it later on the batch page.
Driver earnings
One flat amount in QAR for the whole ride, not per order. Defaults to 5.
Notes
Free text kept on the batch for the driver or the next staff member. Optional.
Select orders
Tick each order for the ride; the header checkbox ticks the whole visible list. The counter shows the running total and Create Batch stays disabled until at least one order is ticked.

Which orders appear

Hub delivery
The order has to be marked as a hub delivery. Ordinary door-to-door orders never show up here.
Verified
Address verification must already be done. Unverified orders are held back until they clear.
Not batched
An order can only ever be on one batch. Once it is on a ride it drops out of this list.

Worth knowing

  • The order list is not filtered by the pickup location you choose — every eligible order is listed. Check the Pickup Location column against your selection before ticking, or the driver will be sent to the wrong door.
  • The batch number is generated for you (BATCH-date-sequence) — there is nothing to type.
  • Anything ticked that has since been batched by someone else is silently dropped when you save, so confirm the order count on the batch page afterwards.
  • Creating the batch does not create any delivery task. Last-mile tasks are only raised when the batch reaches At Hub.
  • Only drivers with approved status can be selected, here or later.
