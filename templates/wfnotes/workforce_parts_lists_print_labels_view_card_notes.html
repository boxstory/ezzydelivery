The packing bench. This page exists for one job: finding orders and printing their waybills — the label that goes on the parcel so it can be identified and matched to the right customer. It opens on the last three days of orders, because those are the packages most likely to be sitting in front of you. Nothing is edited here; printing a label does not publish, assign or change an order in any way.

What you can do here

Client filter
Narrow to one client, or several at once — a bench session is often two or three sellers' parcels together.
Search
Matches order number, customer name or mobile. Handy when a parcel in your hand needs its label reprinted.
Period
Quick ranges — today, yesterday, 3 days, last week, month — filtering on when the order was created. Custom reveals From and To boxes for an exact range. Same control as the orders lists.
Reset
The cross button clears every filter and puts you back on the last three days.
Print one
The printer icon at the end of a row opens that single waybill in a new tab, ready for the browser's print dialog.
Label & Status
Label is the one this bench wants each morning — Not printed yet hides everything already done. Status keeps cancelled orders from being labelled.
Print selected
Tick rows — or the header box to take the whole page — then use the button at the top. Ticks are kept as you page, so a client spanning four pages is still one print job. The count shows the running total and says how many are on other pages.
Print all matching
Appears when the filter matches more than one page. Prints every order in the current filter without ticking anything, up to 500.
Open an order
The order number links to its full detail page, for when the address or COD on a label looks wrong.

What is on a row

Order
The order number, with the client's name underneath.
Customer
Name and mobile — the same details that print on the label.
Address
The written address plus the zone / street / building numbers. Dashes there mean those numbers were never captured.
COD
The cash the driver is meant to collect, in QR. Zero means the order is already paid.

Worth knowing

  • Selection is remembered against the filter you are on. Change the filter and the running selection starts fresh — the old ticks belonged to a different list.
  • The list is every order in the range — published or not, cancelled or not. Printing a label for a cancelled order is possible, so check the order first if you are unsure.
  • Printing now stamps the order, which is what Label filters on. Reprints are still allowed and simply bump the count — the stamp records that a label exists, not that it is on a parcel.
  • Waybills open in a new tab. If nothing appears, the browser has blocked the pop-up.
