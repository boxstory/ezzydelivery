A dry run of the location codes your capacity settings will produce, before any of them exist. Check the shape and the naming read the way the building actually does, then generate — that is the step that creates the real zones, racks, shelves and bins.

Reading the preview

It is abridged
Only the first three racks, shelves and bins are drawn, with a "… n more" line standing in for the rest. The full set is still created.
Codes are joined
Each level is added to its parent's code, so a bin carries its whole address.
Existing locations
The count shown is what this warehouse already has. If it is not zero, you are re-running the setup.

Generating

Safe by default
Locations that already exist are left alone; only missing ones are added.
Delete existing
Wipes every location in this warehouse first. Only for a building with no stock in it — stock rows point at those locations.
Only bins are pickable
Zones, racks and shelves are created as containers, so stock is never placed directly in them.

Good to know

  • Go back and adjust rather than generating a layout you already doubt — renaming afterwards is far more work.
  • Large layouts take a moment to create; let it finish.
