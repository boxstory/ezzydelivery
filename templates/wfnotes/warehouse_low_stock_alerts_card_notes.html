Products that have run down to their reorder point. An alert is raised against a product in a warehouse when its on-hand quantity falls to the level someone set as "time to order more". The page opens on active alerts — the ones nobody has dealt with yet.

What to do with an alert

Acknowledge
Says a human has seen it and action is under way. It takes the alert out of the active list; it does not order anything.
Tell the seller
Restocking is the seller's decision — the warehouse cannot conjure inventory. The alert is the prompt to ask.
Check the figure first
If the shelf disagrees with the alert, the fix is a cycle count, not an acknowledgement.

Reading the list

Status filter
Defaults to active. Switch it to see what has already been acknowledged or resolved.
Per product and warehouse
The same product can be fine in one building and short in another, so it can appear twice.
Reorder point
Set on the stock row, not the product. Alerts that fire constantly usually mean the threshold is wrong.

Good to know

  • Reserved units count against you. Stock promised to orders is not available, which is why an alert can appear while the shelf looks full.
  • The dashboard tile counts active alerts only, so working this page is what brings that number down.
