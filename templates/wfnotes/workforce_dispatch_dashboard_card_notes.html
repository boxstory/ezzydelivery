The live control room for order batching. When an order is verified, the engine looks for another order leaving the same pickup location for the same zone, holds the pair for a few minutes in case a second one turns up, releases it, then hands it to a rider who is clocked in at that location. This page shows that machinery as it runs right now — today's batch counts, every batch still in play, who is on shift, and what the engine did last. Nothing is edited here; the batch, shift and config pages do the editing.

What you can do here

New shift
Schedules a rider at one pickup location for a block of time. A rider with no shift can never be given a batch, so this is the first thing to fix when batches pile up in Ready.
Quick links
All Batches (full history and filters), Manage Shifts, KPI Dashboard, and Config — the per-location batching rules.
Tiles
Counts of batches created since midnight broken down by status, plus the number of shifts currently sitting in Active.
Active batches
The 30 newest batches that are still holding, ready, assigned or in progress. It reloads itself every 10 seconds; the refresh button forces it now. The eye icon opens the batch.
Countdown
On a holding batch, the time left before it is released automatically. At zero it reads "Releasing…" until the background worker picks it up.
Active riders
Everyone on an Active shift, their store and batches done so far. Reloads every 30 seconds.
Activity
The last 20 dispatch log entries across the whole system — batches created, released, assigned, cancelled, shifts started and ended.

Batch statuses

Holding
The hold timer is running and the batch still has room for another order going to the same zone.
Ready
Released — the batch is closed and waiting for a rider. Nobody has it yet.
Assigned
A rider has been given the batch and the delivery tasks for its orders have moved to in-transit under that rider.
In progress
The rider pressed start in the app and is out with the orders.
Completed
The rider closed the batch. This is the point where the shift's batch and order counters go up.
Pending
A batch that exists but has not started its timer yet — normally visible for a fraction of a second.

Worth knowing

  • The tiles count today only, but the active batch list ignores dates — a batch left open from yesterday shows in the list and not in the tiles.
  • Released is not assigned. Releasing only closes the batch to new orders; a separate background pass hands it to a rider a few seconds later.
  • Assignment only ever considers riders with a shift in Active status at that batch's own pickup location, who are approved, under their order and batch limits, and who have enough COD headroom for the cash on the batch.
  • All the timing — releasing expired holds, SLA rescues, auto-assignment, ending shifts — runs on background workers. If those are stopped, batches sit where they are and only a manual release on the batch page will move them.
  • Cancelled batches disappear from this monitor. Use All Batches with the status filter to find them again.
