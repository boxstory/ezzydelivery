## 🎯 USAGE QUICK START

### **1. Basic Integration**
```django
{% load static %}

<!-- In base template head -->
<link href="{% static 'brand-kit-pro.css' %}" rel="stylesheet">
<link href="{% static 'brand-kit-pro-enhanced.css' %}" rel="stylesheet">

<!-- Before closing body tag -->
<script src="{% static 'brand-kit-pro.js' %}"></script>
<script src="{% static 'brand-kit-pro-enhanced.js' %}"></script>
```

### **2. Use Components**
```html
<!-- Toast Notification -->
<script>
EzComponents.success('Order created successfully!');
</script>

<!-- Signature Capture -->
<canvas id="signature" class="signature-capture-canvas"></canvas>
<script>
const sig = new SignatureCapture('#signature');
</script>

<!-- Drag & Drop Upload -->
<div id="upload" class="upload-zone"></div>
<script>
const uploader = new DragDropUpload('#upload', {
  maxFiles: 5,
  acceptedTypes: ['image/*', '.pdf']
});
</script>

<!-- Lazy Load Images -->
<img data-src="image.jpg" class="lazy" alt="Description">

<!-- Bulk Actions -->
<div class="ez-bulk-actions" style="display: none;">
  <div class="ez-bulk-actions__count">
    <span class="ez-bulk-actions__count-number">0</span> selected
  </div>
  <button class="ez-bulk-actions__btn">Delete</button>
  <button class="ez-bulk-actions__btn ez-bulk-actions__btn--primary">Export</button>
</div>

<!-- Inline Editing -->
<div class="ez-inline-edit">
  <span class="ez-inline-edit__display">Click to edit</span>
  <input class="ez-inline-edit__input" value="Click to edit" style="display:none;">
</div>
```
