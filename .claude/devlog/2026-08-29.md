
## 19:15 — Fix "Page Expired" dead-end on driver login / password reset
Driver 110 (Muhammed Kannotan, 71188023) hit the Page Expired screen repeatedly at 19:01–19:04; gunicorn logs show 29 CSRF failures today, all with reason "CSRF cookie not set" on /accounts/login/ and /password/reset/request/. The origin issues the csrftoken correctly, so the cause was the PWA service worker: it cached HTML pages at root scope and replayed them without their Set-Cookie header and with a dead csrfmiddlewaretoken, and the retry link re-served the same cached copy — an unbreakable loop. Fixed on three layers: sw.js now bypasses all auth paths and only keeps offline copies of /fleet/ and /delivery/ pages (bumped to v8 so stale v7 caches are purged), the password-reset pages now send Cache-Control: no-store, and the CSRF failure view mints a fresh cookie onto the 403 itself with a cache-busted retry link plus a script that clears the stale SW page cache — so the very next attempt works. Added 6 regression tests; core suite 126/126.
