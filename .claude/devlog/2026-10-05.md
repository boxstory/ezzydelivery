## 16:52 — Tasks go to one driver or to Public; everything else waits in Unassigned (+ Task Automation rules)
Publishing a task no longer drops it into every driver's PWA New tab. A new `DeliveryTask.public_pool` flag is now the only way into New, and staff choose it in every Assign Driver picker (task page + bulk bar) as "Public — all drivers with app access"; picking a driver puts the task in that driver's Assigned tab only. Publish to Fleets, bulk publish, auto-import, return legs and return pickups now land a driverless task in a new **Unassigned Tasks** list (`/workforce/tasks/unassigned/`, with a Public tab), and unassigning a driver sends it back there, not to Public. A new **Task Automation** page (`/workforce/task-automation/`) holds ordered rules — client / drop-off zone group / task type / speed → one driver or Public — that run once when a task lands in Unassigned (first match wins; a rule whose driver lost app access is skipped), plus a "Run rules now" button for the backlog.

One selector pair in `delivery/selectors.py` (`delivery_pool_for` / `delivery_pool_block`) now decides the New tab, map, dashboard count, scans and all five take/accept paths (incl. the mobile API), and all staff routing goes through `delivery/services/assignment.py`. That closed two real holes: any driver could take a task staff had assigned to someone else via `/fleet/tasks/assign/` (only an `AssignedDriver` row was checked), and that endpoint plus `/fleet/tasks/accept/` wrote the claim row before refusing an unpublished task. Staff assign now also publishes, since an unpublished task was invisible even to its own driver. Migration delivery 0057 (with `db_default`) backfilled the 2 tasks that were in the pool as Public. **Incident:** another session's gunicorn reload picked up the new model field before I migrated — 92 production 500s (fleet dashboard, COD collection, live map) between 16:15 and 16:38 Qatar until 0057 was applied. 47 new tests pass; fleet/delivery/workforce/ezzy_api/orders runs show only failures already on the known pre-existing lists (plus two stale fleet tests from earlier commits).
