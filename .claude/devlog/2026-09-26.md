## 23:07 — Staff can crop a driver document photo, undoably
Added a Crop action to each document card on /workforce/drivers/<id>/. Staff open a Cropper.js modal, drag the box (rotate/reset available for sideways phone scans), and save; the crop is done in the browser and the server only validates the bytes and swaps the file in. Verified the full round trip against a real production document (driver 1322 QID): cropped to 551x657, restored byte-identical to a pre-test backup, cropped file removed from disk, production left exactly as found.
