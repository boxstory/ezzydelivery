## 12:16 — P2P: per-vehicle box count limits, alongside the CBM ceiling

be written as a cubic-metre ceiling (0.141 cbm against 0.090), so no `capacity_cbm` value

has no row, which means no count limit and the CBM rule decides alone exactly as before.
Ops edit it in a new "Box limits" panel on the workforce rate-card page. Effect: 7+ small or
4+ medium boxes now step up from car to SUV (65→85 and 75→95 QAR at 10km express).

## 13:41 — Message bodies gain {if …}{else}{endif} conditions
Staff wanted to word the optional lines themselves instead of taking the wording a ready-made
`{cod_line}` ships with — show a COD line only when there is COD to collect, name the store only
when it is known. The resolver now understands `{if cod_amount}…{else}…{endif}` in any editable
body: one placeholder name per condition, no operators, and an empty OR zero value both count as

Nesting is not supported (first `{endif}` closes). The Messages-page preview resolves the same
rules in JS, both editors carry the syntax hint, and the shipped default wording is unchanged.

## 01:22 — Raise the bulk earnings cap from a guessed 500 to a measured 1500
Staff hit "904 deliveries match this filter — more than the 500 allowed at once" on driver 666935.
The 500 was a number I picked without measuring. Benchmarked the real publish path on an isolated
database: 500 rows in 9.2s, 904 in 19.3s, 1500 in 30.2s — about 20ms a row. The real ceiling is the
gunicorn worker timeout (120s), because publishing writes a row and a wallet transaction per
delivery and a worker killed mid-loop leaves a half-published batch. 1500 sits at ~30s, so it holds
even if production runs three times slower than the bench.

Both guards in the earnings action now read one documented `EARNINGS_BULK_LIMIT` constant — the
select-all-across-pages count check and the posted-id length check, which were separate 500s, so a
904-row publish would have failed twice for different reasons. The other 500s in the file
(client-charge verification, COD settle, payout lines) are different flows and were left alone.
Added boundary tests that patch the constant down rather than build fifteen hundred fixtures, and
one asserting the shipped limit still clears a real month's 904.
