# Dev Log — 2026-09-28

## 19:09 — CRM driver lead: documents panel with viewer/edit popup
Driver lead cards now carry a Documents panel listing every uploaded scan (thumbnail, type, number, expiry state). Clicking a row opens a popup with the full-size scan, a front/back switch when a back side exists, the filed facts, and an Edit button that hands over to the add/edit form — posting to the same `driver_document_save` endpoint the driver record uses. The document-decoration loop was lifted out of `driver_detail` into a shared `driver_document_cards()` helper so the two pages cannot drift, and the type select is opted out of Select2 (`data-no-select2`) because the enhanced widget ignored the prefilled value and would have broken HTML5 validation on a hidden required field.
