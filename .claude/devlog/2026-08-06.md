# Dev Log — 2026-08-06

## 13:50 — Auto Triggers: one ledger instead of three tables

Design pass on `/workforce/auto-triggers/`. The three cards each had their own auto-sized
column widths, so Status/Enabled/Edit zig-zagged by up to 62px down the page — measured, not
guessed. Gave all three tables one shared column grid (`table-layout: fixed` + `atl__col--*`
percentages) so the control rail lands on the same x in every table, and put a single hairline
down its left edge. Section header badges were rendering three different ways (solid yellow,
pale yellow, gold outline) because Bootstrap's `.bg-*` utilities and brandkit-overrides both
use `!important`; they are now one quiet chip. Added a live "n / m on" reading to each section
header that follows the department tabs and updates after every toggle — the page never showed
how much of the system was actually firing. Tightened row padding to the 0.375rem baseline and
moved the inline `width:%` / `cursor:pointer` attributes into CSS. Page height 3654px → 3112px
with no content removed.
