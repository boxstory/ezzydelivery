# Dev Log — 2026-09-02

## 21:09 — Fleet transactions: driver picker becomes COD tiles
Replaced the driver dropdown on /workforce/fleet/transactions/ with a tile grid — one tile per active driver carrying their name, driver code + ID, and the COD they are still holding (with the count of unsettled deliveries behind it). The figure is aggregated from DeliveryTask (cod_collected, not cod_settled), the same source of truth the ledger uses, so it always agrees with the profile card; tiles sort by money held so whoever owes the most is first. Added a client-side filter box, a fleet-wide running total, and a page-local "Change driver" modal reusing the same partial, so switching drivers shows the same information instead of a bare name list.
