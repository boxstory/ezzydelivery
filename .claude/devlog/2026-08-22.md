## 11:58 — Abandoned-inquiry WhatsApp nudge (built, seeded OFF)

Nobody who dropped out of the 3PL form was ever contacted — a partial PricingEnquiry is created at step 1 with their phone number, but `create_lead_from_pricing_inquiry` only fires at final submit, so abandoners never became a CRM lead and no cron ever looked at them. 26 of 142 inquiries (18%) were sitting there unreachable.

Built the next-morning nudge. `quote_token` already defaults on creation, so partials could be given a resume link without a new identifier: new `inquiry_resume` view loads the saved record back into the session and redirects to the first step still missing a required answer (reusing `_missing_pricing_answer`, so "where they stopped" matches what the Next button enforces). Added `_inquiry_to_session_data` as the explicit inverse of the three step savers — booleans go back as 'True'/'False' strings because the form reads session values as POST-shaped text. A lead who has since finished gets redirected to their rate sheet instead of an empty form; a bad token 404s.

The sender is `send_inquiry_resume_nudge`, routed through `crm_leads` like the existing thank-you message so replies land in the sales inbox, gated by a new `wa_inquiry_resume_nudge` trigger on the Auto Triggers page. The command `send_inquiry_resume_nudges` runs each morning: it only picks up inquiries created before midnight Qatar (so nobody mid-form is interrupted), inside a `--max-age-days 3` window so a first run cannot blast the historical backlog, once per inquiry via the new `resume_nudge_sent_at` stamp, and skipping non-Qatar mobiles by default — the abandoned rows carry a lot of overseas scraper traffic (+1, +90). The trigger is checked once up front rather than per row, otherwise a switched-off trigger would stamp every record as nudged without sending.

Seeded DISABLED and no cron installed — this messages prospects directly, so switching it on is a human decision. Verified with --dry-run at both window sizes (1 in the 3-day window, 6 of 8 in 90 days with 2 correctly filtered), and the resume link tested from a cold browser: lands on step 2 with the step-1 answers restored and step-2 blank.
