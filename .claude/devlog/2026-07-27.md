The stored cod_collected flag is deliberately left False because the driver settlement pages count zero-COD deliveries separately through that flag; to keep those counts honest, zero-amount rows are excluded from the ledger's per-method order counts. Added a backfill command for the 235 historical zero-COD deliveries that have no transaction — dry run only so far, not yet applied.
