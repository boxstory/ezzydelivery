# Dev Log — 2026-09-04

## 01:11 — Driver application status page now lists what's missing
The "Application under review" page only told applicants to wait; it now lists the exact gaps in their file, split into required items (the team cannot approve without them) and optional ones that speed the review up. Each row carries an "Add" button that reopens the wizard on that step, plus a main "Update application" button that jumps to the first missing step. Un-typed document numbers are collapsed into a single row so the list stays short, and a complete file gets a green "nothing else is needed" line instead.

**Files:** `core/views.py`, `core/templates/core/join_us_driver.html`, `core/static/core/css/driver-apply.css`
