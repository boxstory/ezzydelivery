EzzyDelivery API Documentation

Connect your e-commerce store and start delivering with EzzyDelivery

📖 Overview

EzzyDelivery API allows you to integrate your e-commerce store (Shopify, WooCommerce, TikTok Shop) with our delivery management platform. Automatically sync orders, track deliveries, and manage COD payments.

✓ Order Management
✓ Real-time Tracking
✓ Webhook Updates
✓ COD Handling

🚀 Quick Start

  1. Create API Key
    Generate credentials in your Settings page
  2. Choose Your Platform
    Select Shopify, WooCommerce, or TikTok Shop
  3. Configure Integration
    Follow platform-specific setup guide
  4. Test Connection
    Verify orders are syncing correctly

✨ Key Features

  • Order Import: Automatically sync orders from your platform
  • Real-time Updates: Webhook notifications for delivery status
  • COD Management: Handle cash-on-delivery transactions
  • Tracking: Provide customers with delivery tracking links
  • API Keys: Secure token-based authentication
