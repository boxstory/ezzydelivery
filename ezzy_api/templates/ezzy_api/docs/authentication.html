🔐 Authentication

Secure your API requests with proper authentication

Authentication Methods

EzzyDelivery API supports two authentication methods:

1. Bearer Token (Recommended)

Use your API key as a Bearer token in the Authorization header:

Authorization: Bearer ezz_key_1234567890abcdef

2. API Key Header

Include your API key in the X-API-Key header:

X-API-Key: ezz_key_1234567890abcdef

Getting Your API Key

Step 1: Create API Key

  1. Log in to your EzzyDelivery account
  2. Go to Settings → API Settings
  3. Click "Create New API Key"

Step 2: Configure Key Permissions

Select which API endpoints your key can access:

  • Read Orders
  • Write Orders
  • Read Deliveries
  • Write Deliveries
  • Read Webhooks
  • Write Webhooks

Step 3: Copy Your Credentials

Key ID: api_key_123456
Secret: sk_live_abcdefghijklmnopqrst

⚠️ Important: Store your secret key securely. Never commit it to version control or expose it in client-side code.

Using Your API Key

cURL Example
curl -X GET "https://api.ezzydelivery.qa/api/integrations/" \
  -H "Authorization: Bearer ezz_key_1234567890abcdef"
Python Example
import requests

headers = {
  "Authorization": "Bearer ezz_key_1234567890abcdef"
}

response = requests.get(
  "https://api.ezzydelivery.qa/api/integrations/",
  headers=headers
)
JavaScript/Node.js Example
const response = await fetch(
  "https://api.ezzydelivery.qa/api/integrations/",
  {
    headers: {
      "Authorization": "Bearer ezz_key_1234567890abcdef"
    }
  }
);

API Key Management

Rotating Your API Key

For security, rotate your API keys regularly:

  1. Go to API Keys settings
  2. Click "Rotate Key" next to your key
  3. A new key will be generated
  4. Old key remains active for 24 hours (for migration)
  5. Update all integrations to use the new key

Disabling a Key

  1. Go to API Keys settings
  2. Click "Disable" next to the key
  3. Key will immediately stop working
💡 Use cases: Disable a key if you suspect it's been compromised

Security Best Practices

✓ Do's

  • Store API keys in environment variables
  • Use HTTPS for all API requests
  • Rotate keys periodically (monthly recommended)
  • Use limited permission scopes
  • Monitor API usage for anomalies

✗ Don'ts

  • ✗ Never commit API keys to version control
  • ✗ Don't use API keys in client-side JavaScript
  • ✗ Don't share keys with other team members
  • ✗ Don't use the same key for multiple apps

Test Your Authentication

Use our interactive tools to test your API key and endpoints:

Using Swagger UI for Testing

  1. Go to Swagger UI
  2. Click the "Authorize" button in the top-right
  3. Select "Bearer" and enter: Token your_api_key_here
  4. Click "Authorize" to confirm
  5. Find an endpoint and click "Try it out"
  6. Click "Execute" to test the request
📚 Available Testing Tools:
  • Swagger UI — Interactive endpoint testing with "Try it out" button
  • ReDoc — Beautiful API documentation viewer
  • OpenAPI Schema — Raw JSON schema for tools and IDEs
✓ Success: If you see a successful response, your API key and authentication are working correctly!

Environment Variables

Store your API key in environment variables:

.env file
EZZYDELIVERY_API_KEY=ezz_key_1234567890abcdef
EZZYDELIVERY_API_URL=https://api.ezzydelivery.qa
Load in Python
import os
from dotenv import load_dotenv

load_dotenv()
api_key = os.getenv('EZZYDELIVERY_API_KEY')
Load in Node.js
require('dotenv').config();
const apiKey = process.env.EZZYDELIVERY_API_KEY;
