🎵 TikTok Shop Integration

Connect your TikTok Shop and manage deliveries

How It Works

TikTok Shop integration uses OAuth 2.0 authentication. This allows secure connection to your TikTok seller account without sharing credentials.

✓ Supports: TikTok Shop in Middle East / Asia Pacific regions

Prerequisites

  • Active TikTok Shop seller account
  • Verified business information in TikTok Shop
  • EzzyDelivery account

Setup Steps

Step 1: Register Your App with TikTok

  1. Go to TikTok Seller Platform → App Management
  2. Click "Create App"
  3. Select app type: "Third-party Application"
  4. Fill in:
    • App Name: EzzyDelivery Logistics
    • App Type: Fulfillment Service
    • Description: Delivery and logistics management platform
  5. Click "Create"

Step 2: Configure OAuth Redirect

Set where TikTok redirects after authorization:

Redirect URI:
https://api.ezzydelivery.qa/api/integrations/tiktokshop/callback/
  1. In your TikTok app settings, find "OAuth Configuration"
  2. Add the redirect URI above
  3. Save changes

Step 3: Get Your Credentials

TikTok will provide you with:

📝 Your App Credentials

App ID: 123456789
App Secret: abcdef1234567890ghijklmnop
Client Key: cli_abc123def456
Client Secret: sk_live_123456789abcdefghijk

Step 4: Request Required Permissions

Ensure your app has these scopes:

  • seller.order.read - Read orders
  • seller.fulfillment.write - Update fulfillment status
  • seller.shop.read - Read shop info

    • Step 5: Add Integration in EzzyDelivery

    1. Log in to EzzyDelivery
    2. Go to Settings → API Settings
    3. Click "New Integration"
    4. You'll be redirected to TikTok to authorize
    5. Log in with your seller account
    6. Click "Allow" to grant permissions
    7. Redirected back to EzzyDelivery (success!)

    Sync Fulfillment Status

    Update TikTok Shop with delivery status automatically:

    Send Delivery Status to TikTok
    POST /api/integrations/tiktokshop/update-status/

    {
      "tiktok_order_id": "7384932847593842",
      "fulfillment_status": "delivered",
      "tracking_info": {
        "carrier": "EzzyDelivery",
        "tracking_number": "EZZY-2024-123456",
        "estimated_delivery": "2024-04-20"
      }
    }

    Supported Fulfillment Status:

    • processing - Order received, preparing
    • in_transit - Package in delivery
    • delivered - Successfully delivered
    • exception - Delivery exception / issue

    Troubleshooting

    ❓ Authorization Failed

    Issue: TikTok shows "Invalid redirect URI"
    Solution: Verify the URI matches exactly: https://api.ezzydelivery.qa/api/integrations/tiktokshop/callback/

    ❓ Permission Denied

    Issue: "Insufficient permissions" error
    Solution: Ensure your TikTok app has been approved with these scopes: seller.order.read, seller.fulfillment.write

    ❓ Orders Not Importing

    Issue: Orders not showing in EzzyDelivery
    Solution: Run test connection to verify authorization is still valid

    ❓ Different Region/Shop

    Issue: Need to connect different TikTok Shop
    Solution: Disconnect current shop in Settings and create new connection
