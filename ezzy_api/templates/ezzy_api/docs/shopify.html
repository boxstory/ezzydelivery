🛒 Shopify Integration

Connect your Shopify store with EzzyDelivery

How It Works

The Shopify integration uses OAuth 2.0 authentication. This allows you to securely connect your Shopify store without sharing your password.

✓ Secure OAuth: Your store credentials are never shared with EzzyDelivery

Setup Steps

Step 1: Create a Shopify App

Go to your Shopify Admin and create a custom app for EzzyDelivery:

  1. Log in to your Shopify Admin → Settings → Apps and integrations
  2. Click "Develop an app"
  3. Enter app name: EzzyDelivery
  4. Click "Create app"

📝 Example

App name: EzzyDelivery Delivery Integration

Step 2: Configure App Permissions

Grant necessary permissions to read orders:

  1. Go to Configuration tab
  2. Under Admin API scopes, enable:
    • read_orders
    • read_products
    • read_customers
  3. Click "Save"
💡 Why these permissions? We need to read orders and customer details to create delivery tasks.

Step 3: Set Redirect URI

Configure where Shopify will redirect after authorization:

Redirect URI:
https://api.ezzydelivery.qa/business/shopify/oauth/callback/
  1. In Shopify app Configuration, find Redirect URLs
  2. Add the redirect URI above
  3. Click "Save"

Step 4: Get Your Credentials

Shopify will provide you with:

📝 Your App Credentials

Client ID: 123abc456def789ghi
Client Secret: shpca_1234567890abcdefghijklmnopqr
API Version: 2024-01 (recommended)

Step 5: Add Integration in EzzyDelivery

In your EzzyDelivery business account, set up the integration:

  1. Log in to EzzyDelivery Dashboard
  2. Go to Settings → API Settings
  3. Click "New Integration" button
  4. Select "Shopify" from the platform list
  5. Enter your Shopify details:
    • Store URL: yourstore.myshopify.com
    • Client ID: Copy from Shopify app settings
    • Client Secret: Copy from Shopify app settings
  6. Click "Authorize with Shopify"

Step 6: Complete OAuth Authorization

You'll be redirected to Shopify's authorization page:

  1. Review the permissions EzzyDelivery is requesting
  2. Click "Allow" to grant access
  3. You'll be redirected back to EzzyDelivery
  4. Your Shopify integration status will show "Active"
✓ Success! Your Shopify store is now connected and ready to import orders

Import Orders

After connecting, you can import orders from your Shopify store:

API Endpoint
POST /api/integrations/shopify/import/
Request Body
{
  "store_url": "mystore.myshopify.com",
  "order_ids": [
    5548199579,
    5548199580
  ],
  "date_from": "2024-04-01"
}

Manual Order Import

Import past orders that were placed before integration:

Example: Import Orders from Last 7 Days
POST /api/integrations/shopify/import/

{
  "store_url": "mystore.myshopify.com",
  "date_from": "2024-04-10",
  "date_to": "2024-04-17"
}
💡 Tip: Use date_from and date_to to import historical orders in batches.

Troubleshooting

❓ Authorization Failed

Issue: Shopify shows "Invalid redirect URI"
Solution: Verify the redirect URI exactly matches: https://api.ezzydelivery.qa/business/shopify/oauth/callback/

❓ Orders Not Importing

Issue: Orders aren't showing in EzzyDelivery
Solution: Check that your Shopify app has read_orders permission enabled

❓ Missing Customer Address

Issue: Delivery address is incomplete
Solution: Ensure customers enter full delivery address at checkout in Shopify

Still stuck? Check Error Handling or contact support@ezzydelivery.qa
