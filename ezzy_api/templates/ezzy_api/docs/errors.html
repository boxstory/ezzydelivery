⚠️ Error Handling

Common errors and how to fix them

Error Response Format

{
  "status": "error",
  "error": "Invalid API key",
  "error_code": "INVALID_AUTH",
  "message": "The provided API key is not valid or has expired"
}

Common Errors

401 - Unauthorized

Cause: Invalid or missing API key

Solution: Check that your API key is correct and included in the Authorization header

400 - Bad Request

Cause: Invalid request parameters

Solution: Check request body format and required fields

404 - Not Found

Cause: Resource doesn't exist

Solution: Verify the order ID or integration ID is correct

429 - Too Many Requests

Cause: Rate limit exceeded

Solution: Wait and retry. Current limit: 1000 requests/hour

500 - Server Error

Cause: Internal server error

Solution: Contact support if the issue persists
