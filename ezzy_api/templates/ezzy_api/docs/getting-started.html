Getting Started with EzzyDelivery API

Setup your integration in 5 minutes

1. Create an API Key

First, you need to generate API keys to authenticate with our API.

Steps:
  1. Log in to your EzzyDelivery account
  2. Go to Settings → API Settings
  3. Click "Generate API Key"
  4. Give your key a name (e.g., "Shopify Integration")
  5. Copy your API Key and Secret (store safely)

📝 Example API Key

// After creating, you'll receive:
Key: ezz_key_xxxxxxxxxxxxxxxxxxxx
Secret: ezz_secret_xxxxxxxxxxxxxxxxxxxx

2. Choose Your Platform

Select which e-commerce platform you want to integrate:

Uses OAuth for secure authorization

3. Authentication

All API requests require authentication. Include your API key in the request header:

HTTP Header
Authorization: Bearer your_api_key_here

📝 Example Request

curl -X GET "https://api.ezzydelivery.qa/api/integrations/" \
  -H "Authorization: Bearer ezz_key_1234567890abcdef"

4. Test Your Connection

Once you have your API key, test the connection:

1

Make a test request to list your integrations

GET /api/integrations/
2

Expected response

{
  "status": "success",
  "integrations": [
    {
      "id": 1,
      "type": "shopify",
      "name": "My Shopify Store",
      "status": "active"
    }
  ]
}
3

If you get an error

Check that your API key is correct and included in the header. See Error Handling for common issues.

Interactive API Testing Tools

Before writing code, test your API integration using our interactive documentation tools:

Available Tools
  • Swagger UI — Interactive explorer with "Try it out" button to test endpoints in real-time
  • ReDoc — Beautiful, responsive API documentation for browsing endpoints
  • OpenAPI Schema — Raw JSON schema for tooling integration and IDE support

🚀 How to Use Swagger UI

  1. Open Swagger UI
  2. Click the "Authorize" button
  3. Enter your API key in the format: Token your_api_key_here
  4. Find an endpoint and click "Try it out"
  5. Fill in parameters and click "Execute"
  6. See the request and response in real-time

5. Webhook Setup

Enable real-time updates for order status changes:

  1. Go to Webhook Settings
    Settings → Webhooks → Add Webhook Endpoint
  2. Enter Your URL
    The URL where you want to receive updates (e.g., https://yourstore.com/webhook/order-status)
  3. Select Events
    Choose which events trigger webhooks (order.created, delivery.updated, etc.)
  4. Verify Webhook
    We'll send a test request to verify your endpoint is working
💡 Tip: Use webhook events to update your store with delivery status in real-time.

6. Sync Your First Order

After setup, you can import orders from your platform:

Example: Import from Shopify
POST /api/integrations/shopify/import/

Request body:
{
  "store_url": "mystore.myshopify.com",
  "order_ids": [123456, 123457]
}

📝 Response Example

{
  "status": "success",
  "imported": 2,
  "orders": [
    {
      "order_id": "ORD-001",
      "customer": "John Doe",
      "delivery_address": "123 Main St, Doha",
      "status": "imported"
    }
  ]
}
