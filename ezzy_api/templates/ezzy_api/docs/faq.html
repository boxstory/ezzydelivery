❓ Frequently Asked Questions

Common questions about EzzyDelivery API

General

Q: How do I get started with the EzzyDelivery API?

A: Start with the Getting Started guide. You'll need to create an API key and choose your integration platform (Shopify, WooCommerce, or TikTok Shop).

Q: Is the API free to use?

A: API access is included with your EzzyDelivery subscription. Usage limits depend on your plan.

Q: What are the API rate limits?

A: Currently 1000 requests per hour per API key. Contact support for higher limits.

Integration

Q: Can I integrate multiple stores?

A: Yes! You can connect multiple Shopify, WooCommerce, or TikTok Shop stores to a single EzzyDelivery account.

Q: How long does integration setup take?

A: Usually 5-10 minutes. Follow the platform-specific setup guide for your e-commerce platform.

Q: Can I disconnect an integration?

A: Yes, go to Settings → Integrations and click "Disconnect" next to the integration.

Orders & Delivery

Q: How are orders imported?

A: Orders can be imported manually via API, automatically via webhooks, or through scheduled syncs.

Q: Can I import historical orders?

A: Yes, use the date_from parameter to import orders from any date range.

Q: What order statuses are supported?

A: Each platform supports different statuses (pending, processing, completed, etc.). Check the platform-specific guide.

Security

Q: How are API keys secured?

A: Use HTTPS for all requests and store keys in environment variables. Never commit keys to version control.

Q: Can I rotate my API key?

A: Yes, go to Settings → API Keys and click "Rotate" next to your key.

Q: What if my API key is compromised?

A: Immediately disable the key in Settings, create a new one, and update all integrations.

Support

Q: How do I get help?

A: Check our documentation, contact support@ezzydelivery.qa, or visit our support portal.

Q: What are the support hours?

A: We provide 24/7 support for all customers. Response time is typically within 2 hours.

Q: Is there a test/sandbox environment?

A: Use your development Shopify/WooCommerce store for testing before going live.
