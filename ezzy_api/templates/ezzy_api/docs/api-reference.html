Integration Endpoints

List Integrations

GET /api/integrations/

Description: Get list of all configured integrations

Response Example:

{
  "status": "success",
  "integrations": [
    {
      "id": 1,
      "type": "shopify",
      "name": "My Store",
      "status": "active"
    }
  ]
}

Import Shopify Orders

POST /api/integrations/shopify/import/

Description: Import orders from your Shopify store

Request Body:

{
  "store_url": "mystore.myshopify.com",
  "order_ids": [123456, 123457],
  "date_from": "2024-04-01"
}

Import WooCommerce Orders

POST /api/integrations/woocommerce/import/

Description: Import orders from your WooCommerce store

Import TikTok Shop Orders

POST /api/integrations/tiktokshop/import/

Description: Import orders from your TikTok Shop

Order Management

Get Orders

GET /api/business/orders/

Query Parameters:

  • status - Filter by order status
  • date_from - From date (YYYY-MM-DD)
  • date_to - To date (YYYY-MM-DD)
  • page - Page number (default: 1)

Get Order Detail

GET /api/business/orders/{order_id}/

Description: Get detailed information about a specific order

API Key Management

Create API Key

POST /api/api-keys/create/

Description: Create a new API key for your account

List API Keys

GET /api/api-keys/

Description: Get list of all your API keys

Common Response Codes

Code Meaning Example

400 Bad Request Invalid parameters
401 Unauthorized Invalid API key
403 Forbidden Insufficient permissions
404 Not Found Resource doesn't exist
500 Server Error Internal server error
