📨 Webhooks

Receive real-time order and delivery updates

What are Webhooks?

Webhooks allow you to receive real-time notifications when events happen in EzzyDelivery. Instead of polling our API repeatedly, we'll send you data whenever an event occurs.

Webhook Events

📦 order.created

Triggered when a new order is imported

🚚 delivery.assigned

Triggered when an order is assigned to a driver

📍 delivery.updated

Triggered when delivery status changes

✅ delivery.completed

Triggered when delivery is completed

❌ delivery.failed

Triggered when delivery fails

Webhook Payload

Example Webhook Data

{
  "event_type": "delivery.updated",
  "timestamp": "2024-04-17T10:30:00Z",
  "data": {
    "order_id": "ORD-001",
    "status": "in_transit",
    "driver_name": "Ahmed",
    "estimated_delivery": "2024-04-17T14:00:00Z"
  }
}

Setup Your Webhook Endpoint

  1. Create an endpoint on your server that accepts POST requests
  2. Verify webhook signatures for security
  3. Respond with 200 OK to acknowledge receipt
  4. Log webhook data for debugging
