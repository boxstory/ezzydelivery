📦 WooCommerce Integration

Connect your WordPress/WooCommerce store

How It Works

WooCommerce integration uses API key authentication. Generate API credentials in your WordPress admin, then use them to connect with EzzyDelivery.

Setup Steps

Step 1: Generate API Keys in WordPress

  1. Log in to your WordPress Admin Dashboard
  2. Go to WooCommerce → Settings → Advanced → REST API
  3. Click "Create an API key"
  4. Fill in the form:
    • Description: EzzyDelivery Integration
    • User: Select your admin account
    • Permissions: Read
  5. Click "Generate API key"

Step 2: Copy Your Credentials

WooCommerce will generate Consumer Key and Consumer Secret:

📝 Example Credentials

Consumer Key: ck_live_123abc456def789ghi
Consumer Secret: cs_live_1234567890abcdefghijklmnopqr
Store URL: https://mystore.com

Step 3: Add Integration in EzzyDelivery

  1. Log in to EzzyDelivery Dashboard
  2. Go to Settings → API Settings
  3. Click "New Integration" button
  4. Select "WooCommerce" from the platform list
  5. Enter your WooCommerce credentials:
    • Store URL: https://yourstore.com
    • Consumer Key: From WordPress REST API
    • Consumer Secret: From WordPress REST API
  6. Click "Test Connection" to verify
  7. Click "Save Integration"
✓ Success! Your WooCommerce store is now connected

Webhook Configuration

Configure WooCommerce webhooks to receive real-time order updates. These are set up in your WordPress admin, not in EzzyDelivery.

Setup Webhook in WordPress

  1. Go to WooCommerce → Settings → Advanced → Webhooks
  2. Click "Add webhook"
  3. Fill in:
    • Name: EzzyDelivery Order Events
    • Status: Active
    • Topic: Order Created / Order Updated
    • Delivery URL:
      • https://api.ezzydelivery.qa/api/webhooks/order/inbound/{YOUR_WEBHOOK_KEY}/
  4. Click "Save webhook"
💡 Get Your Webhook Key: This is provided when you create the integration in EzzyDelivery

Filter Orders by Status

You can import orders with specific statuses:

Example: Import Only Completed Orders
POST /api/integrations/woocommerce/import/

{
  "store_url": "https://mystore.com",
  "status": "completed",
  "date_from": "2024-04-10"
}

Supported Order Statuses:

  • pending - Payment pending
  • processing - Payment received, processing
  • completed - Order completed
  • on-hold - Waiting for action

Troubleshooting

❓ Connection Failed

Issue: "Invalid API credentials"
Solution: Verify Consumer Key and Consumer Secret are correct. Copy them exactly as shown in WordPress.

❓ Orders Not Syncing

Issue: Webhook events aren't triggering
Solution: Check webhook status in WordPress and verify delivery URL is correct

❓ Address Format Issues

Issue: Delivery address format is wrong
Solution: Ensure customer shipping address is complete (Street, City, Postcode, Country)
